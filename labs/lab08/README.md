# Lab 8: Browser Physics Simulation

This browser simulation ports the Lab 7 physics engine to JavaScript, with a canvas renderer, projectile and spring scenes, live energy HUD, and validation tools; to run it, open this folder in VS Code and choose **Open with Live Server** on `index.html`, or run `py -m http.server 8000` from this folder and visit <http://localhost:8000/> (serve it over HTTP because JavaScript modules do not run correctly from a `file://` URL). Use **Integrator** to switch between Velocity Verlet, Euler-Cromer, and Euler without resetting; **Scene** to choose the Part A coordinate diagram, projectile, or spring oscillator; **DT** to choose 1/240, 1/120, 1/60, or 1/20 s; and **Timestep mode** to choose the fixed accumulator or variable frame dt. **Pause/Resume** and **Reset** control the run (Space toggles pause and R resets); **Induce 500 ms lag** measures each mode's response; **Validate at t = 2.0 s** runs the built-in checks; and **Run 10 s headless** prints the C1 projectile state. The canvas HUD displays time, position, speed, kinetic and potential energy, total energy, step count, active timestep mode, and integrator; validation results appear in the page log and the Part A Vec2 checks also appear in the browser Console.
