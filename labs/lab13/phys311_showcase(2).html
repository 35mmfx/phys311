Physics 311 -- Student Project Showcase

Interactive physics simulations built from scratch by junior-level mechanics students. No physics libraries. Every project below states a measured accuracy.

What you're looking at

Physics 311 (Mechanics) is an asynchronous online course in which students learn classical mechanics by computing it.  Over fourteen weeks they build numerical solvers in Python, assemble them into a modular physics engine, port that engine to JavaScript, and publish an interactive simulation or simple game to the open web.

The projects below are the final deliverable.  Each one was written by a single undergraduate using only the browser's built-in Canvas API — no game engine, no physics library.  The dynamics, collision handling, and numerical integration are the student's own code.

One thing distinguishes this gallery from most student project pages: every entry reports a validated number.  Students are required to measure their simulation's accuracy -- energy drift, momentum conservation, convergence order, or agreement with an analytic limit -- and to publish that measurement alongside the work.  A simulation nobody validated is just an animation.

About the Course

Physics 311 covers the standard junior-level mechanics sequence from Taylor's Classical Mechanics, but reorganizes it so that every topic is implemented numerically. Students write the solver, then validate it against a conservation law or an analytic limit, then build on it.

BlockWeeksFocus
11–3Newton's laws, projectile motion, energy as a diagnostic, oscillations and phase space — in Python
24–7Momentum, central forces, angular momentum; assembling a modular physics engine
38–10Porting the engine to JavaScript; HTML5 Canvas; interactivity and publishing
411–13Scoping, building, validating, documenting, and launching a public project

Tools: VS Code, Python (NumPy / Matplotlib / Jupyter), JavaScript with HTML5 Canvas, Git and GitHub, GitHub Pages.

The recurring theme: a conservation law is a test suite. Students spend the semester learning that the hard part of computational physics is not making something move — it is knowing whether what you made is right, and being able to prove it to someone else.

Note on authorship and privacy. All projects are published with student consent.  Some students have chosen to appear under a display name or without attribution; participation in this showcase is optional and carries no effect on course grades.  Source repositories and license terms are linked from each project.
